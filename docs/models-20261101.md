# Gemino 新旧模型推理包 / Inference packages

两个包各自独立，解压后不依赖原训练电脑路径，无需额外基础权重。仅含推理权重、配置和加载代码，不含训练视频、人物照片、优化器、服务器连接信息。

| 包 | 结构 | 首选步数 | 输入→输出 | 选择依据 |
|---|---|---:|---|---|
| attention150000.zip | 论文指导的自实现分块Attention，非官方精确复现 | 150000 | 128→512，单参考 | 325固定验证帧最低LPIPS-Squeeze v0.1：0.10178134 |
| flow99000.zip | 基于Gemino的旧光流模型、自定义适配 | 99000 | 128→512，单参考 | 旧模型最低验证总损失；基础参数与微调覆盖参数已合并 |

这里“旧模型”指本轮训练的512光流模型；仓库原有v0.1.0的256→1024人物模型仍保留，两者不是同一权重。新模型19万步未超过15万步，本次不将19万步作为首选发布。

## 使用

在独立Python环境安装适合显卡的PyTorch，再运行`pip install -r requirements.txt`。推荐Python3.10、PyTorch2.5.1；训练环境PyTorch2.8。无需下载VGG/LPIPS网络即可推理。

Attention包：

```sh
python inference.py --reference ref512.png --reference-lr ref128.png --target-lr target128.png --output output.png
```

旧光流包：

```sh
python inference.py --reference ref512.png --target-lr target128.png --output output.png
```

图片必须是RGB且尺寸精确512或128；脚本不会隐式裁剪或调整几何。Attention的ref128应为与ref512对应的解码低清参考。训练使用VP8低清输入；本入口从已解码PNG读取，不模拟视频码率。连续视频需要逐帧解码并复用参考；没有在线参考更新或多参考接口。

`weights.pt`支持`torch.load(...,weights_only=True)`，使用`inference.load_model()`严格恢复所有参数；`config.json`为配套配置。`manifest.json`记录所有文件SHA256，发布总清单记录压缩包SHA256。支持CPU，默认有CUDA则使用CUDA。

## 已知限制与来源

训练素材来自CelebV-HQ候选池，5502训练片段、325验证片段；来源隔离，跨来源人物身份未严格去重。LPIPS首选依据验证集，不应称为独立盲测。15万步14人诊断共2506目标帧：平均LPIPS0.112648、SSIM0.899652、PSNR31.1985dB；相比同输入双三次LPIPS降低42.17%，但6段PSNR下降。眼镜、低头、大幅转头仍有平滑、偏色和残影。

上游Gemino：https://github.com/geminovc/model 。保留`licenses`和`THIRD_PARTY_NOTICES.md`。旧模型包含FOMM继承组件及其非商业许可，不得将顶层MIT解释成覆盖所有依赖与权重的许可。新实现也不替代原数据来源、第三方预训练模型和相关权利的条款。包中没有重新授权训练数据或附带人物素材。
